# Дом Пацыка — виджет для Android

Пацык живёт на рабочем столе: рыбачит, спит, ест, сам включает и выключает свет,
смотрит в окно на настоящую погоду и надевает шапку в мороз.
Нажми на виджет — откроется меню (покормить, погладить, рыбалка, спать, свет).

## Как собрать APK через GitHub (без Android Studio)

1. Зайди на github.com → «New repository» → любое имя (например `dom-patsyka`) → **Create repository**.
2. На странице репозитория нажми **uploading an existing file**.
3. Перетащи в окно **всё содержимое** распакованной папки `DomPatsyka`
   (папки `app`, `.github` и файлы `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`, `README.md`).
   → **Commit changes**.
4. Открой вкладку **Actions**. Сборка «Собрать APK» запустится сама (≈ 3–6 минут).
   Если Actions попросит разрешение — нажми зелёную кнопку, чтобы включить их.
5. Когда появится зелёная галочка — открой эту сборку, внизу в разделе **Artifacts**
   скачай `Dom-Patsyka-APK`. Это zip, внутри — `app-debug.apk`.

### Если папка .github не загрузилась
На главной странице репозитория: **Add file → Create new file**, в имени файла напиши
`.github/workflows/build.yml` и вставь содержимое файла `.github/workflows/build.yml` из архива.

## Как поставить на телефон (Samsung Galaxy)

1. Перекинь `app-debug.apk` на телефон (Telegram, Google Drive, кабель).
2. Если Samsung не даёт установить: **Настройки → Безопасность и конфиденциальность →
   Автоблокировщик** → выключить (после установки можно включить обратно).
3. Открой APK → разреши установку из этого источника → **Установить**.
4. Открой приложение **«Дом Пацыка»** один раз и **разреши геолокацию** — она нужна для погоды
   (без неё погода будет для Киева).
5. Зажми пустое место на рабочем столе → **Виджеты** → **Дом Пацыка** → перетащи на экран (4×2).

## Настройки (в файле `Logic.kt`)
- `DARK_CHANCE_DAY` / `DARK_CHANCE_EVENING` — как часто Пацык выключает свет.
- `HUNGRY_AFTER_HOURS` — через сколько часов без еды он грустит.
- `ACTION_MINUTES` — сколько длится действие из меню.
